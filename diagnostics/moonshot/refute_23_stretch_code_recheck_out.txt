REPLICATES EXACTLY: probe-23's D_pose = 0.3030 / 0.3131 / 0.3686 / 0.3382 vs clean 0.1850.
CODE CHECKS THAT DID NOT REFUTE:
  - J_names and kintree_table are byte-identical across all three templates.
  - J_regressor is a dense ndarray in all three (no sparse-matrix handling bug).
  - betas width == shapedirs width in every run (25/25, 13/13, 20/20); sd[:,:,:K] was a no-op.
  - the forward convention (deform_verts in POSED space, propagate_scaling=False) is correct for
    ALL SIX corpora INCLUDING the clean one: rel. residual 6.9e-04 vs 2.8e-01 / 1.6e+00 / 1.4e+00
    for the three alternatives. probe-23b's "MISMATCH" label on clean is not a wrong forward model.
  - cross-template L0 differences are too small to make 0.185 into 0.35 for the LIM arms
    (OmniAnt25/SMPL_fit leg mean|log| = 0.063 prox / 0.061 dist).
WHAT REFUTES IT:
  - betas_trans does not exist in the clean corpus (the parameter is absent from the npz and the
    clean verts reconstruct with it zeroed). Zeroing it in the worker arms collapses the published
    gap from 1.64-1.99x to 0.98-1.09x under probe-23's own body-bone normaliser.
  - the second contributor is the ROOT joint's scale, which is a 1.16-1.17x ISOTROPIC whole-animal
    size factor (|log iso| 0.15-0.16 worker vs 0.052 clean) with anisotropy no larger than clean's
    (1.11-1.20 vs 1.14). Removing it too gives 0.89-1.19x under every normaliser.
  - the pretarsus headline (1.97-2.01x, BPX/M7) is measured against SMIL_OmniAnt, whose template
    pretarsus bones are left/right asymmetric by up to 2.90x (l_2_pt_l 0.0353 vs l_2_pt_r 0.1022).
